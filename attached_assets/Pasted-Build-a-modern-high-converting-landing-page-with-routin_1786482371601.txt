Build a modern, high-converting landing page with routing and a Sender.net email capture integration for a local 9x12 Co-Op Postcard Advertising agency ("LocalReach 9x12").

Architecture & Routing:
- Multi-page setup using client-side routing (e.g., React Router or Next.js / Express backend):
  * Main Landing Page ("/")
  * Privacy Policy Page ("/privacy-policy")
  * Terms & Conditions Page ("/terms")
- Header and Footer must persist across all pages.

Sender.net Integration & Backend Hook:
- Create a backend API route (e.g., POST `/api/subscribe`) to handle form submissions securely without exposing API keys on the client side.
- Environment Variables required in .env:
  * SENDER_API_TOKEN (Sender.net API v2 bearer token)
  * SENDER_GROUP_ID (Sender.net Group/List ID for 9x12 leads)
- When the contact form is submitted, the backend should send a POST request to Sender.net API v2:
  * Endpoint: `https://api.sender.net/v2/subscribers`
  * Headers: 
    - Content-Type: application/json
    - Authorization: Bearer ${SENDER_API_TOKEN}
    - Accept: application/json
  * Request Body Payload:
    {
      "email": "<user_email>",
      "firstname": "<user_name>",
      "phone": "<user_phone>",
      "groups": ["<SENDER_GROUP_ID>"],
      "fields": {
        "business_name": "<business_name>",
        "industry_category": "<category_selected>"
      }
    }
- Handle success (200/201) by returning a JSON response to the front-end to trigger the confirmation modal.
- Handle error states gracefully with fallback UI alerts.
